Core Capabilities

## What Makes the Thread X3 Different

Broadband communications backbone for data-intensive monitoring projects requiring high-speed data transfer.

#### Integrated 4G/LTE Modem

Global SIM card pre-provisioned for 600+ cellular networks across 190 countries. No carrier setup or physical SIM provisioning required — simply power on and connect.

#### LPWA Wireless Mesh

Automatic network role detection using MQTT-SN standard. Functions as Gateway, Repeater or Endpoint — self-organising mesh for robust multi-node deployments.

#### 3 Versatile Input Channels

Channel 1: USB, RS232, RS485, 4-20mA. Channels 2-3: RS232, RS485, 4-20mA. Multiplexer support connects up to 128 sensors. Relay output for actuator control.

#### Multi-Power Flexibility

Internal 12.8V 9.9AH LiFePO4 battery with 3-day backup. Direct solar panel connection (160W max). AC power input. Low-power mode (20mA) for energy-sensitive deployments.

#### End-to-End Encryption

Data secured with TLS 1.2 encryption over cellular, Ethernet or mesh networks. Support for JSON data forwarding to cloud platforms via MQTT, REST API or FTP.

#### Zero-Touch Configuration

Configuration via cloud platform with no on-site setup required. Remote management, firmware updates and diagnostics — deploy and manage at scale.
